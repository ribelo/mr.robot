# Issue tracker

The tracker is Markdown files in this repository.

- Specs: docs/issues/<slug>.md with story IDs (prefix `robot`).
- Tickets: docs/issues/<spec-slug>/NN-<slug>.md, numbered in dependency order, each naming the tickets that block it; README.md in that directory is the index.
- Triage is the `Status` field: ready-for-agent, in-progress, done.
