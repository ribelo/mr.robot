## Features named, one line each (as stated)

- Redesigned chat cards: markdown tables, questions with A/B/C and multi-select options.
- "Bot's computer" responses three times faster (second upgrade in two weeks).
- Draft edits highlighted: when the bot revises a draft (Slack, Gmail), the revisions are highlighted.
- Plus-addressed e-mail aliases for the bot's e-mail address (e-mail addresses for bots launched the week before); asked for in chat.
- X: the bot reads and answers the user's X DMs, with limits against spam.
- X: @bot in an X thread does what the user asks; needs the X plugin installed and configured; the X username is linked to the account.
- New connectors: Robinhood, Coinbase, Trello, PostHog "and many more".
- Voice calls: the bot keeps the memory of a call (full transcript) for 30 minutes after hang-up.
- Notifications collapsed: one notification on the device the user is active on, not every device.
- Invite teammates (team and enterprise accounts).
- Android: Grok Bot can be the default Android assistant.
- Team bot access lists: delegate who has access to a team bot.
- Mobile: an "unread" pill that jumps to unread messages.
- Routine times: improvements when scheduling a routine.
- Slack sign-in links: a better sign-in flow when the bot needs Slack and the user is not signed in.
